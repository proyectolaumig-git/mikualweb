# MIKUAL · Sitio web

Código del sitio web de **MIKUAL · Solutions Technology Lab**, laboratorio de soluciones tecnológicas para negocios.

🌐 **Sitio:** [mikual.com](https://mikual.com)

> **Cuestionamos. Elegimos. Construimos.**

## Acerca del sitio

- Sitio estático hecho con **HTML, CSS y JavaScript**, sin frameworks ni dependencias.
- Bilingüe: español (raíz) e inglés (`/en/`).
- Publicado con **GitHub Pages** y servido siempre por **HTTPS**.

## Estructura

```
├── index.html          Inicio
├── metodo.html         Método
├── diagnostico.html    Diagnóstico
├── soluciones-*.html   Soluciones (Operación, Ejecución, Información)
├── nosotros.html       Nosotros
├── agendar-llamada.html  Agenda una llamada
├── aviso-de-privacidad.html
├── en/                 Versión en inglés
└── assets/             Estilos, scripts e imágenes
```

## Seguridad

- No hay servidor, base de datos, formularios, cuentas ni cookies propias.
- El repositorio no contiene llaves, contraseñas ni datos privados.
- Cada página incluye una política de seguridad de contenido (CSP) que solo permite recursos del propio sitio y de los servicios externos que usa.

Si encuentras un problema de seguridad, escríbenos a **contacto@mikual.com** en lugar de abrir un *issue* público.
